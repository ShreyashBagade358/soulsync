# SoulSync - Modern Dating App with AI Matching

A full-stack dating application with sophisticated matching algorithms, real-time messaging, and AI-powered recommendations.

## Quick Start

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm start
```

## Documentation

- [README](README.md) - Project overview and features
- [DEPLOYMENT.md](DEPLOYMENT.md) - Production deployment guide

## Features

- **Smart Matching Algorithm**: Multi-layer scoring with distance, interests, age, and behavioral analysis
- **User Embeddings**: AI-powered taste profiling
- **Real-time Messaging**: WebSocket-based chat
- **Swipe System**: Like, Dislike, and SuperLike
- **Geolocation**: Location-based matching

## Tech Stack

**Backend:** Node.js, Express, MongoDB, Redis, Socket.IO  
**Frontend:** React, Tailwind CSS, Framer Motion, Zustand
